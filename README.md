# doc-qa-rag-assistant

A Retrieval-Augmented Generation (RAG) application in Python: ingest PDF documents, ask questions about them in natural language, and get grounded answers with source citations.

> **Based on a tutorial.** The core code in this repository comes from Tech With Tim's
> [ProductionGradeRAGPythonApp](https://github.com/techwithtim/ProductionGradeRAGPythonApp).
> I built it as a learning project to understand how a production-style RAG pipeline works,
> and made the small changes listed below. All credit for the original design and code goes to the original author.

## What I learned

- How documents are split into chunks, embedded and stored in a vector database
- How semantic search retrieves relevant context for an LLM to answer from
- How event-driven workflows (Inngest) add retries, throttling and rate limiting to an AI pipeline
- How to connect a FastAPI backend and a Streamlit front-end

## Features

- PDF ingestion and chunking (LlamaIndex)
- Vector storage and semantic search with Qdrant (local, cosine similarity)
- Event-driven workflows with Inngest, with automatic retries
- Throttling and per-source rate limiting on ingestion
- Answers generated by an OpenAI model, returned with the source documents used
- FastAPI backend and Streamlit front-end
- Batch ingestion of a whole folder of PDFs

## Tech stack

- Python 3.13
- FastAPI + Uvicorn
- Inngest
- LlamaIndex (`llama-index-core`, `llama-index-readers-file`)
- Qdrant (`qdrant-client`)
- OpenAI API (embeddings and answers)
- Streamlit
- `uv` for dependency management

## How it works

1. **Ingest:** a PDF is loaded and split into chunks. Each chunk is embedded and stored in Qdrant with an ID based on the source document and chunk number.
2. **Query:** the question is embedded and used to find the most relevant chunks in Qdrant. Those chunks are sent as context to an OpenAI model, which writes an answer and returns the sources it used.
3. Both steps run as Inngest functions (retries, throttling, rate limiting) and are served over HTTP by FastAPI.

## Getting started

### Prerequisites

- Python 3.13+
- [`uv`](https://docs.astral.sh/uv/)
- An OpenAI API key
- Node.js (to run the Inngest dev server with `npx`)

### Installation

```bash
git clone https://github.com/joinsrikanth945/doc-qa-rag-assistant.git
cd doc-qa-rag-assistant
uv sync
```

### Configuration

Create a `.env` file in the project root:

```
OPENAI_API_KEY=your-key-here
# optional: folder used by ingest_all.py (default ./pdfs)
PDF_FOLDER=./pdfs
```

### Run

```bash
# terminal 1: start the FastAPI / Inngest backend
uv run uvicorn main:app --reload --port 8000

# terminal 2: start the Inngest dev server
npx inngest-cli@latest dev -u http://127.0.0.1:8000/api/inngest

# terminal 3: start the Streamlit UI
uv run streamlit run streamlit_app.py
```

Open http://localhost:8501 for the app and http://localhost:8288 for the Inngest dashboard.

To ingest a whole folder of PDFs at once (with the backend and Inngest running):

```bash
uv run python ingest_all.py
```
